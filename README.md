## 📖 About
**Rizoma** is a simulation of an **administrative dashboard** designed to showcase modern React development best practices.  
Built with **Next.js 15** and **TypeScript**, it provides a clean architecture and interactive UI components.  
It incorporates:

- **TanStack Table** for powerful and flexible data tables
- **Zod** for schema validation and type-safe data handling
- **ShadCN/UI** and **Radix UI** for accessible and customizable UI elements
- **Zustand** for lightweight and efficient state management

This project is ideal as a learning reference or as a base for building production-ready dashboards.

---

## 🛠 Tech Stack
- **Next.js 15** — React framework for SSR, SSG, and advanced routing.
- **TypeScript** — Strongly typed JavaScript for safer and more scalable code.
- **React 19** — JavaScript library for building user interfaces.
- **Tailwind CSS 4** — Utility-first CSS framework.
- **Radix UI** + **shadcn/ui** — Accessible and customizable UI components.
- **React Hook Form** + **Zod** — Typed form handling and validation.
- **@tanstack/react-query** — Asynchronous data fetching and caching.
- **@tanstack/react-table** — Flexible and performant data table rendering.
- **Zustand** — Lightweight global state management.
- **Recharts** — Data visualization and charts.
- **GSAP** — High-performance animations.
- **@dnd-kit** — Drag-and-drop functionality.
- **Axios** — HTTP requests.
- **Husky** + **Lint-Staged** — Git hooks and code quality automation.
